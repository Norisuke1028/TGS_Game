# BURGER CRAFT

## 概要
本作品は、東京ゲームショウ（TGS）への出展を目標に制作した、バーガー作成シミュレーションゲームです。
コントローラーを使用し、次々に来店するお客様の注文に合わせて正確かつ素早くバーガーを調理・提供します。

不特定多数の来場者が短時間でプレイする環境を想定し、直感的な操作性と、プレイ結果が形に残るリザルト・ランキング機能を重視して設計しました。

## 制作背景
東京ゲームショウ（TGS）への出展作品。
来場者がその場で遊び、評価がダイレクトに返ってくる環境を想定し、「短時間でルールを理解でき、かつスコア更新を目指したくなる競技性」を軸にチームで開発しました。

## 開発情報
- **開発期間**: 約3か月
- **制作人数**: 3人
- **開発環境**: Visual Studio 2022
- **使用言語**: C / C++

## 工夫した点

### ■ シーン間のデータ受け渡し処理
- ゲームメインからリザルト画面へ、スコアやプレイ情報を正確に引き継ぐ仕組みを構築。
- シーン遷移後もデータを安定して保持し、正確な結果表示と再利用性の高い構造を実現しました。

### ■ ランキング反映処理
- 取得したスコアをもとに、比較・ソート（並び替え）を行い、即座に順位へ反映するロジックを実装。
- プレイヤーが自分の結果を直感的に把握できるよう、UIの表示構成にも配慮しました。

### ■ 領域を超えたクリエイティブへの挑戦
- プログラム実装に加え、自らイラスト制作にも着手。
- デザイナーとエンジニアの両方の視点を持つことで、ゲーム全体のビジュアルとプログラムの親和性を高めました。

## 苦労した点
- 経験のなかったシーン跨ぎのデータ管理やランキングアルゴリズムの論理設計。
- TGSという絶対的な納期に向け、自身のプログラム実装とイラスト制作を両立させるスケジュール管理。

## 学んだこと
- 自身の担当に固執せず、他分野（イラスト等）に挑戦することでスキルの幅が広がることの実感。
- チーム開発における担当外のメンバーとの連携や、共通データの受け渡しの重要性。
- ユーザーの継続意欲を高めるための「結果表示」の演出と設計の難しさ。
